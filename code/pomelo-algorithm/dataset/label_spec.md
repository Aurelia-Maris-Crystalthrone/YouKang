# 柚子病虫害图像标注规范

> 核心原则：宁可丢弃，不要乱标。错误标注比不标注更可怕。

---

## 一、标注工具

推荐使用 **LabelImg**（开源、简单、支持 YOLO 格式）。

### 安装

```bash
pip install labelimg
```

### 启动

```bash
labelimg
```

### 操作要点

1. 打开图片目录：`File → Open Dir`
2. 设置标注保存目录：`File → Change Save Dir`
3. 选择 YOLO 格式：`PascalVOC → YOLO`（左下角切换）
4. 开始标注

## 二、类别定义

| 类别 | 编号 | 中文名 | 说明 |
|------|------|--------|------|
| red_spider_mite | 0 | 红蜘蛛 | 整图伪框，检测全叶受害症状 |
| anthracnose | 1 | 炭疽病 | 真框，检测病斑 |
| canker | 2 | 溃疡病 | 真框，检测病斑 |
| greening | 3 | 黄龙病 | 整图伪框，检测全叶黄化症状 |
| healthy | - | 健康叶 | 不标注，空标注文件 |

**注意**：
- healthy 不占类别编号，标注为空 txt 文件
- red_spider_mite 和 greening 用整图伪框（框覆盖整张图）
- anthracnose 和 canker 用真框（框住病斑）

## 三、框的紧贴程度

### 3.1 真框（anthracnose, canker）

| 要求 | 说明 |
|------|------|
| 紧贴病斑 | 框的上、下、左、右紧贴病斑边缘 |
| 不包背景 | 框内尽量只包含病斑，不包健康组织 |
| 不切病斑 | 病斑不能被框切掉 |
| 多病斑 | 每个病斑一个框 |

**正确示例**：
```
病斑在框内，框边缘紧贴病斑，不包健康组织
```

**错误示例**：
```
框太大，包了很多健康组织
框太小，切掉了病斑边缘
框偏移，病斑不在框中心
```

### 3.2 整图伪框（red_spider_mite, greening）

| 要求 | 说明 |
|------|------|
| 覆盖整图 | 框的坐标为 (0, 0, 1, 1)（归一化坐标） |
| 不偏移 | 框必须覆盖整张图 |
| 单框 | 每张图只有一个框 |

**为什么用整图伪框**：
- 红蜘蛛虫体约 0.5mm，640×640 输入不可见
- 检测目标是全叶受害症状，不是虫体
- 黄龙病表现为全叶黄化，不是局部病斑

## 四、多病斑处理

### 4.1 同一类别多病斑

```
图片中有 3 个炭疽病斑 → 标注 3 个框
```

每个框独立标注，不合并。

### 4.2 不同类别多病斑

```
图片中有 1 个溃疡病斑 + 2 个炭疽病斑 → 标注 3 个框
```

每个框按类别标注。

### 4.3 病斑重叠

```
两个病斑重叠 → 分别标注，框可以重叠
```

### 4.4 病斑接近边界

```
病斑接近图片边界 → 框可以超出边界，LabelImg 会自动处理
```

## 五、模糊/存疑图片处理

### 5.1 处理原则

**宁可丢弃，不要乱标。**

错误标注会导致：
- 模型学习到错误的特征
- 测试集评估不准确
- 答辩时被评委质疑

### 5.2 判断标准

| 场景 | 处理方式 |
|------|----------|
| 完全模糊 | 丢弃，不标注 |
| 部分模糊（病斑清晰） | 标注清晰部分 |
| 病斑不明显 | 丢弃，不标注 |
| 不确定是什么病 | 丢弃，不标注 |
| 非目标作物 | 丢弃，不标注 |
| 其他病害（如脂点黄斑病） | 丢弃，不标注 |

### 5.3 存疑图片处理

```
不确定 → 不标注 → 丢弃
```

**不要**：
- 猜测类别
- 标注为"疑似 XX"
- 保留存疑图片

## 六、标注流程

### 6.1 单张图片标注

1. 打开图片
2. 按 `W` 键进入标注模式
3. 选择类别
4. 拖动鼠标画框
5. 按 `Enter` 确认
6. 按 `D` 键切换到下一张

### 6.2 批量标注

1. 按类别分目录
2. 每个目录单独标注
3. 标注完成后，检查标注文件
4. 删除不合格图片

### 6.3 标注检查

```bash
# 检查标注文件数量与图片数量是否一致
ls selfcollect/red_spider_mite/*.jpg | wc -l
ls selfcollect/red_spider_mite/*.txt | wc -l

# 检查标注文件是否为空（healthy 应为空）
find selfcollect/healthy -name "*.txt" -size 0 | wc -l

# 检查类别编号是否正确
# 查看 txt 文件第一列
cut -d' ' -f1 selfcollect/red_spider_mite/*.txt | sort | uniq -c
```

## 七、标注文件格式

### 7.1 YOLO 格式

```
class_id x_center y_center width height
```

- `class_id`：类别编号（0-3）
- `x_center, y_center, width, height`：归一化坐标（0-1）

### 7.2 示例

**真框（炭疽病）**：
```
1 0.5 0.5 0.2 0.3
```

**整图伪框（红蜘蛛）**：
```
0 0.5 0.5 1.0 1.0
```

**健康叶（空文件）**：
```
（空文件，无任何内容）
```

## 八、常见错误

### 8.1 框太大

```
错误：框包了很多健康组织
正确：框紧贴病斑
```

### 8.2 框太小

```
错误：框切掉了病斑边缘
正确：框包含整个病斑
```

### 8.3 类别错误

```
错误：把炭疽病标成溃疡病
正确：根据区分特征判断
```

### 8.4 健康叶标注了框

```
错误：健康叶标注了框
正确：健康叶为空文件
```

### 8.5 模糊图片标注了

```
错误：模糊图片也标注了
正确：丢弃模糊图片
```

## 九、标注质量检查

### 9.1 抽检

标注完成后，随机抽取 10% 的图片进行人工检查：
- 框是否正确
- 类别是否正确
- 是否有多标/漏标

### 9.2 交叉检查

两人分别标注同一批图片，对比标注结果：
- 一致率应 ≥ 95%
- 不一致的图片重新标注

### 9.3 模型辅助检查

用现有模型对标注数据进行预测，检查：
- 模型预测与标注不一致的图片
- 可能是标注错误，需要人工确认
